# 虚拟电厂优化改进流程方案

## 一、总体目标

从虚拟电厂聚合商角度，扩展柔性负荷资源类型，增强调度优化能力，提升系统对需求响应的支撑能力。

## 二、改进范围

### 不涉及功能
- EV双向充电（V2G）
- 现货市场交易模块
- 辅助服务市场竞价

### 核心改进内容

| 序号 | 功能模块 | 优先级 | 预计工作量 |
|-----|---------|-------|-----------|
| 1 | EV充电站模型（单向） | ⭐⭐⭐ | 中 |
| 2 | 工业可中断负荷模型 | ⭐⭐⭐ | 中 |
| 3 | 商业楼宇空调模型 | ⭐⭐ | 大 |
| 4 | 价格型需求响应 | ⭐⭐⭐ | 中 |
| 5 | 激励型需求响应 | ⭐⭐⭐ | 中 |
| 6 | 多时间尺度调度 | ⭐⭐⭐ | 大 |
| 7 | 不确定性场景生成 | ⭐⭐ | 大 |
| 8 | 可视化增强 | ⭐⭐⭐ | 中 |

## 三、详细设计方案

### 3.1 EV充电站模型（单向充电）

#### 模型特点
- 充电功率可调（慢充/快充）
- 充电时段约束（用户到达/离开时间）
- 充电需求量约束（用户SOC需求）
- 批量充电调度能力

#### 配置参数
```yaml
ev_charging_station:
  num_chargers: 20          # 充电桩数量
  charger_power_kw: 7       # 单桩功率（慢充）
  fast_charger_power_kw: 30 # 快充桩功率
  num_fast_chargers: 5      # 快充桩数量
  operating_cost_yuan_mwh: 20  # 运行成本
  
  # 充电需求模式
  demand_pattern:
    morning_peak: [7, 9]    # 早高峰时段
    evening_peak: [17, 21]  # 晚高峰时段
    avg_energy_demand_kwh: 30  # 平均充电需求
```

#### 调度策略
- 价格型：低谷时段集中充电
- 需求型：满足用户即时充电需求
- 有序充电：避免电网过载

### 3.2 工业可中断负荷模型

#### 模型特点
- 可中断容量分级（一级/二级/三级）
- 中断补偿机制
- 中断时长约束
- 响应时间约束

#### 配置参数
```yaml
interruptible_loads:
  industrial_plant_1:
    rated_power_mw: 5       # 额定功率
    interruptible_ratio: 0.3 # 可中断比例
    interruption_levels:     # 中断级别
      level_1: {capacity_mw: 1, response_time_min: 10, compensation_yuan_mwh: 500}
      level_2: {capacity_mw: 0.5, response_time_min: 30, compensation_yuan_mwh: 300}
      level_3: {capacity_mw: 0.3, response_time_min: 60, compensation_yuan_mwh: 150}
    max_interruption_hours: 4  # 单日最大中断时长
    min_recovery_hours: 2      # 最小恢复时长
```

### 3.3 商业楼宇空调模型

#### 模型特点
- 热惯性模型（温度变化滞后）
- 舒适度约束（温度范围）
- 预冷/预热策略
- 峰值削减能力

#### 配置参数
```yaml
building_hvac:
  office_building_1:
    rated_power_mw: 2        # 额定功率
    cop: 3.5                 # 能效系数
    thermal_mass_kwh_per_c: 500  # 热容量
    temperature_range: [20, 26]  # 舒适温度范围
    outdoor_temp_pattern: [5, 8, 10, 12, 15, 18, 20, 22, 24, 25, 26, 25, 24, 22, 20, 18, 15, 12, 10, 8, 6, 5, 4, 3]
    pre_cooling_hours: 2     # 预冷时长
```

### 3.4 价格型需求响应

#### 机制设计
- 分时电价（峰/平/谷）
- 实时电价响应
- 价格弹性矩阵
- 用户响应模型

#### 配置参数
```yaml
price_based_dr:
  enabled: true
  tariff_structure:
    peak_hours: [8, 11, 18, 21]    # 峰时
    valley_hours: [0, 7]           # 谷时
    peak_price_ratio: 1.5          # 峰时电价倍数
    valley_price_ratio: 0.5        # 谷时电价倍数
  
  elasticity_matrix:
    self_elasticity: -0.3          # 自弹性
    cross_elasticity: 0.1          # 交叉弹性
```

### 3.5 激励型需求响应

#### 机制设计
- 直接负荷控制（DLC）
- 可中断负荷（IL）
- 需求侧竞价
- 激励补偿机制

#### 配置参数
```yaml
incentive_based_dr:
  enabled: true
  
  direct_load_control:
    enabled: true
    controllable_loads: ["chiller", "heat_pump"]
    max_control_hours: 4
    control_interval_min: 15
    incentive_rate_yuan_mwh: 200
  
  interruptible_load:
    enabled: true
    interruptible_capacity_mw: 5
    interruption_duration_hours: 2
    compensation_rate_yuan_mwh: 400
```

### 3.6 多时间尺度调度

#### 调度层次
```
┌─────────────────────────────────────────────────────────────┐
│  年度/季度调度                                                │
│  ├── 合同电量分解                                            │
│  ├── 设备检修计划                                            │
│  └── 燃料采购计划                                            │
├─────────────────────────────────────────────────────────────┤
│  日前调度（24小时）                                           │
│  ├── 机组启停计划                                            │
│  ├── 储能充放电计划                                          │
│  ├── 可调负荷调度计划                                        │
│  └── 电网交易计划                                            │
├─────────────────────────────────────────────────────────────┤
│  日内滚动调度（4-6小时）                                      │
│  ├── 超短期负荷预测                                          │
│  ├── 新能源出力修正                                          │
│  └── 调度计划调整                                            │
├─────────────────────────────────────────────────────────────┤
│  实时调度（5-15分钟）                                        │
│  ├── AGC自动发电控制                                         │
│  ├── 频率调节                                                │
│  └── 功率平衡                                                │
└─────────────────────────────────────────────────────────────┘
```

### 3.7 不确定性场景生成

#### 不确定性来源
- 负荷预测误差
- 新能源出力波动
- 电价波动
- 设备故障

#### 场景生成方法
- 蒙特卡洛模拟
- 情景树构建
- 场景削减技术

## 四、实现路线图

### Phase 1：新增柔性负荷模型（1-2周）
1. 实现EV充电站模型
2. 实现工业可中断负荷模型
3. 更新配置文件
4. 编写测试用例

### Phase 2：需求响应机制（1-2周）
1. 实现价格型需求响应
2. 实现激励型需求响应
3. 集成到调度优化
4. 验证测试

### Phase 3：高级调度功能（2-3周）
1. 实现多时间尺度调度框架
2. 实现不确定性场景生成
3. 集成所有功能
4. 系统测试

### Phase 4：可视化增强（1周）
1. 新增资源可视化
2. 需求响应可视化
3. 多时间尺度可视化
4. 综合报告生成
